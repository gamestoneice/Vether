# Погодное приложение на FastAPI

Красивое веб-приложение для просмотра текущей погоды в любом городе мира, построенное на FastAPI с использованием HTML, CSS и JavaScript.

## Особенности

- **Современный интерфейс**: Адаптивный дизайн с градиентами, анимациями и карточками.
- **Работа с реальными данными**: Интеграция с OpenWeatherMap API для получения актуальной погоды.
- **Fallback на демо данные**: Если API ключ не настроен, приложение автоматически использует реалистичные демо данные.
- **Поиск по городу**: Введите название города и получите температуру, влажность, ветер, давление и описание.
- **Геолокация**: Кнопка "Мое местоположение" определяет ваш город автоматически.
- **Полностью на русском**: Интерфейс и данные о погоде на русском языке.

## Установка и запуск

### 1. Клонирование и настройка

```bash
git clone <репозиторий>
cd test1
```

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 3. Настройка API ключа (опционально)

Для работы с реальными данными зарегистрируйтесь на [OpenWeatherMap](https://openweathermap.org/api) и получите бесплатный API ключ.

Затем установите переменную окружения:

```bash
set OPENWEATHER_API_KEY=ваш_ключ  # Windows
# или
export OPENWEATHER_API_KEY=ваш_ключ  # Linux/Mac
```

Если ключ не установлен, приложение будет использовать демо данные.

### 4. Запуск сервера

```bash
python main.py
```

Или с помощью uvicorn:

```bash
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

### 5. Открыть в браузере

Перейдите по адресу [http://localhost:8000](http://localhost:8000)

## API Endpoints

- `GET /` – главная страница с интерфейсом
- `GET /api/weather?city=Москва` – JSON данные о погоде для указанного города
- `GET /health` – проверка работоспособности сервера

## Используемые технологии

- **Backend**: FastAPI, Uvicorn, httpx, Pydantic
- **Frontend**: HTML5, CSS3 (Flexbox, Grid, анимации), JavaScript (ES6)
- **Иконки**: Font Awesome
- **Шрифты**: Google Fonts (Poppins, Roboto)
- **Погодные данные**: OpenWeatherMap API (или демо)
