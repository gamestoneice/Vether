Как это работает?

Приложение использует API OpenWeatherMap для получения актуальных метеоданных. Вы можете ввести любой город в мире или использовать ваше текущее местоположение.

Данные обновляются в реальном времени. Для получения точного прогноза убедитесь, что название города написано правильно.
